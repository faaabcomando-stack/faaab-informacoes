Gerenciar conteúdos

Altere notícias, cargos e titulares, requisitos, cursos, catálogo e histórico em arquivos estruturados. Sem senhas no código nem acesso público de escrita.

Selecione um arquivo para editar.

Orientações rápidas

Para inserir o ocupante atual de um cargo, preencha titular com objeto contendo username, robloxId e avatarUrl. Para ex-ocupantes, use a lista anteriores com nomes e períodos confirmados.

Imagens de unidades: logo com URL HTTPS da imagem autorizada, ou null para “Não definido”.

Notícias: cada entrada tem data, titulo e resumo. Cadastre somente fatos ou comunicados confirmados.

Como publicar com segurança

Depois de baixar o JSON atualizado, abra o repositório faaabcomando-stack/faaab-informacoes com sua conta GitHub autenticada, selecione dados/nome-do-arquivo.json, edite e confirme as alterações. Não envie senhas ou tokens em arquivos do site.

O avatar do Roblox pode usar um link público de imagem, quando cadastrado e autorizado. Uma integração automática com API do Roblox e um painel com permissões reais exigem serviço de autenticação e backend adicional; não existem neste painel estático.

Os dados publicados em JSON são públicos, incluindo nomes e IDs de usuários cadastrados; não registre informações privadas nem dados de menores sem consentimento apropriado.
